# Sistema de Gestión y Control de Asistencia - Universidad Julio Vermi

Proyecto Final del curso **Programación Orientada a Objetos (SI34)** - UTP (Equipo 07).

## Características técnicas
- Arquitectura modular en paquetes (`modelo`, `excepciones`, `persistencia`, `servicio`).
- Implementación de los 4 pilares de POO: Abstracción, Herencia, Encapsulamiento y Polimorfismo.
- Uso de Clases Genéricas (`<T>`), Colecciones, Expresiones Lambda y Stream API.
- Persistencia de datos mediante serialización de objetos en archivos `.dat`.
